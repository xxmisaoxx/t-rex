Value delta is `0x300`: RVA `0x1300` lies in the memory-only tail and has preferred VA `0x140001300`. It has **no file byte**; `0x700` is merely extrapolated arithmetic and is not a valid mapping for this value. Runtime addresses require the actual loaded base.
